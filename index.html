Work directly with your text

Generate
Turn a prompt into text or code, with independent requests for multiple selections.
Edit
Apply an instruction to each selection and replace it with the result.
Ask
Discuss selected text or your buffer in a Markdown conversation panel, with follow-up questions.

Choose model profiles, cancel pending requests, and connect HTTP tools and MCP tools when your workflow needs them.

Start with your own provider

  1. Install GAI using the installation guide.
  2. Open GAI: Settings and configure your endpoint, model, and API key.
  3. Select text and run GAI: Generate text, GAI: Edit …, or GAI: Ask ….

GAI requires Sublime Text build 4213 or newer with the Python 3.14 plugin host. Provider accounts and usage charges are separate. MCP tools also require an external Python environment.

Your selected text or buffer context is sent to your configured provider. Review your provider and tool settings before sending sensitive content.
